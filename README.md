# Realm Game Initiative

A design space for complete, self-contained realm games that may later become accessible through Talvaren.

## Status

**IDEATION**

Nothing in this repository is Talvaren canon unless Butch explicitly approves it for Talvaren and it is separately recorded there.

Ideas, analysis, examples, and possible mechanics are not approved merely because they appear in conversation. Do not add mechanics to these documents unless Butch explicitly approves them. A mechanic becomes established for a realm game only when Butch unmistakably approves or locks it.

## Shared Realm-Game Framework

- Realm games are compact, system-focused games.
- Each realm game supports no more than five players.
- Each realm game is instanced and is not an MMO.
- Each realm game is built around one strong playable activity.
- Every realm game has five tiers.
- Realm games prioritize clear gameplay, advancement, danger, and replayability over heavy graphics, elaborate simulations, or traditional quest chains.
- A player creates a new character for the realm game.
- The player's Talvaren class and level do not apply inside the realm game.
- A realm game may later be accessible through Talvaren.
- Realm-game play may provide real game-side rewards. Reward forms and rules must be approved separately.

## Design and Implementation Rules

These realm games follow Talvaren's established development discipline:

- Use the simplest readable implementation that performs the approved gameplay function.
- Prioritize playability and clear feedback over graphical weight or decorative fidelity.
- Reuse shared mechanics wherever practical.
- Do not create bespoke simulations, extra reactions, particles, animation work, scenes, scripts, effects, abstractions, or adjacent features without Butch's explicit approval.
- Do not overengineer.
- Keep systems engine-feasible, performance-aware, economical with CPU, and readable through play.
- Presentation and technical shortcuts may support the experience, but they may not rewrite approved world truth.
- Unresolved ideas, examples, analysis, and suggestions are not canon.
- Exceptions and added mechanics require Butch's explicit approval.
