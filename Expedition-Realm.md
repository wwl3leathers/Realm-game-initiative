# Expedition Realm

## Status

**IDEATION**

This document records only concepts explicitly approved by Butch. It is not Talvaren canon.

## Established Direction

- This is an instanced, system-focused realm game for no more than five players.
- It has five tiers.
- It is centered on expeditions.

## Undecided

What an expedition consists of, its destination, progression, rewards, and all other mechanics remain undecided.
